# Better Tracker 0.9.3

Release de corrección: arregla la compilación del APK en GitHub Actions y
actualiza la integración con el sistema de archivos de Android.

### Corregido: build de Android en el workflow

- El job `build-android` fallaba en `:tauri-plugin-android-fs:checkReleaseAarMetadata`:
  `tauri-android` 2.12 exige `compileSdk` 36+, pero el plugin 2.0.1 compilaba
  contra `android-34`.
- `tauri-plugin-android-fs` pasa de la serie 2.x (febrero 2025) a **30.2.0**,
  que usa `compileSdk = 36` y es compatible con Tauri 2.12.
- Se elimina el parche manual del registro de Cargo que solo existía en equipos
  locales; ahora el build funciona igual en CI y en local.

### Migración de la API SAF

- `DirPath`/`FilePath` → `FsUri`; `EntryPath` → `Entry`.
- Selector de carpeta: `picker().pick_dir()` con
  `persist_uri_permission()` para conservar el acceso entre reinicios.
- Creación de archivos con `create_new_file()` + `write()`.
- Guardado del APK en `Descargas` con `create_new_file()` +
  `open_file_writable()`, manteniendo el respaldo por selector SAF en Android
  antiguo.

### Compatibilidad

- Las bóvedas ya seleccionadas siguen funcionando: se acepta la ruta guardada
  por el plugin 2.x (`topTreeUri`/`relativeTerms`), la nueva
  (`uri`/`documentTopTreeUri`) y una URI `content://` plana.
- No hay cambios en el formato de datos de `omega` ni de `Longlife`.

> **Android:** la APK se firma con la misma clave que 0.8.7. Si vienes de una
> versión anterior a 0.8.7, desinstala una vez; desde 0.8.7 se instala encima
> con normalidad.
