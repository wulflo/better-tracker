# Better Tracker 0.9.14

Release de distribución para Microsoft Store. No cambia el formato de la
bóveda (`omega/`) ni de las copias (`longlife/`).

### Microsoft Store (MSIX)

- Nueva build independiente para la Store con `npm run build:store`.
- El paquete MSIX **no incluye** `tauri-plugin-updater`: dentro de la Store la
  app es de solo lectura y las actualizaciones las instala Microsoft Store.
- El panel de actualizaciones detecta el formato `msix`, oculta el botón de
  comprobación y explica que la app se actualiza desde la Store.
- Workflow manual `.github/workflows/store-msix.yml` que genera un `.msix` sin
  firmar y lo deja como artifact de Actions. No toca las releases de GitHub.
- Documentación de identidad de Partner Center, generación del paquete y notas
  de instalación en `docs/MICROSOFT_STORE.md`.

### Privacidad

- Nueva `PRIVACY_POLICY.md` bilingüe (español e inglés) con el detalle de los
  datos locales, las conexiones de red y el caso de Microsoft Store.
- Enlace «Ver política de privacidad» en Ajustes, desde los README y con el
  dominio permitido en el validador de enlaces externos.

### Verificación

- `npx tsc --noEmit` correcto.
- `npm test`: 64 pruebas en 9 archivos.
- `npm run build` correcto.
- `cargo check` con y sin `--no-default-features --features microsoft-store`.
- `tauri build --no-bundle --config src-tauri/tauri.store.conf.json --
  --no-default-features --features microsoft-store` correcto.
- Manifiesto MSIX generado y validado con la versión `0.9.14.0`.

### Nota de actualización

- Las builds de GitHub Releases mantienen el actualizador con firma minisign.
- Los datos existentes se conservan intactos: solo se añaden eventos nuevos.
