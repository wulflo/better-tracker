# Better Tracker v0.8.2

Primera release publicada solo para Linux y Windows, con el pipeline, los manifiestos y la documentación limitados a esas plataformas.

- Interfaz en cuatro secciones: Panel, Entrenamiento, Historial y Figura corporal.
- Logo original integrado en la app, el splash y los iconos compilados de Linux y Windows, sin contenedor circular ni máscara adicional.
- Builds para Linux (AppImage/DEB/RPM) y Windows (NSIS/MSI).
- Actualizaciones manuales, firmadas con minisign y verificadas antes de instalar.
- Manifiesto `latest.json` con entradas para Linux x86_64 y Windows x86_64. La actualización automática solo se ofrece para AppImage; DEB/RPM se actualizan manualmente.
- Claves de firma del updater en GitHub Actions Secrets; el repositorio solo contiene la clave pública.
- Nuevo gráfico de descenso de grasa basado en las medidas guardadas. El % de grasa y la cintura permiten seguir el progreso sin báscula; la masa grasa en kg aparece cuando también hay peso.
- Nuevo registro de comidas por día en la tarjeta de ingesta y saciedad dual: borrador efímero que se borra al terminar el día.
- Base local con más de 200 alimentos comunes, búsqueda sin acentos, alimentos personalizados guardados en la bóveda y cantidades en gramos, mililitros, unidades, tazas, cucharadas, porciones y otras medidas.
- Cálculo dinámico de calorías, proteína, carbohidratos, grasas y fibra según cantidad y medida.
- Guardado de ingesta como un único log por fecha; volver a guardar el mismo día actualiza el log de ese día de forma determinista.
- Correcciones de layout, calendario, heatmap, modales, figura corporal y precedencia del peso.
- Pruebas unitarias de métricas, cálculos de alimentos, alimentos personalizados y borrador diario; verificación de artefactos en CI.

La bóveda sigue siendo JSONL append-only, local y sin cifrado. No hay cuentas ni telemetría; la única conexión es la comprobación manual de actualizaciones. Los valores nutricionales son aproximados y orientativos.
