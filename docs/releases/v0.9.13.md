# Better Tracker 0.9.13

Release de edición de entrenamiento. No cambia el formato de la bóveda
(`omega/`) ni de las copias (`longlife/`).

### Rutinas editables

- El selector de ejercicios para crear o editar rutinas permite buscar por
  **nombre o zona** y filtrar por zona corporal.
- Las rutinas guardadas se pueden **renombrar** sin crear duplicados.
- Al editar una rutina se pueden **desmarcar ejercicios** para excluirlos,
  volver a marcarlos, añadir ejercicios nuevos y ajustar series, repeticiones,
  carga y descanso.
- La reducción de rutinas conserva siempre la última versión guardada de cada
  rutina.

### Renombrar ejercicios

- La biblioteca permite renombrar cualquier ejercicio guardado en línea.
- El cambio se propaga automáticamente a rutinas, sesiones, historial,
  gráficos de progreso y marcas personales, que referencian el ejercicio por
  `id` y muestran siempre el nombre actual.
