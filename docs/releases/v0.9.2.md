# Better Tracker 0.9.2

Esta versión cambia el almacenamiento de la bóveda, elimina la sincronización
P2P/LAN y completa el flujo de Android para elegir carpeta y actualizar la APK.

### Bóveda en `omega`

- Todos los datos de la app viven ahora en `<bóveda>/omega`.
- Los eventos siguen siendo JSONL append-only por dispositivo en
  `omega/devices/<id>/events.jsonl`.
- En escritorio, los datos antiguos de `<bóveda>/devices` se migran una sola vez
  a `<bóveda>/omega/devices` al abrir la bóveda.

### Android: selector de carpeta SAF

- El botón **Seleccionar bóveda** abre el selector de carpetas del sistema.
- El permiso de lectura/escritura se conserva entre reinicios mediante
  `tauri-plugin-android-fs`.
- Se corrige el error «ese permiso de SAF no está configurado» que aparecía al
  intentar cambiar de bóveda.

### Copias diarias en `Longlife`

- Cada día se crea una copia idéntica de `omega` en
  `<bóveda>/Longlife/<AAAA-MM-DD>`.
- Se conservan las 7 copias más recientes.
- La app no usa `Longlife` como fuente de datos: solo enumera las copias para
  mostrar su estado y borrarlas. Para restaurar, mueve el contenido de una copia
  a `omega` manualmente.
- Ajustes muestra el estado de las copias, permite crear la de hoy y ofrece una
  acción de alto riesgo para borrarlas todas con confirmación. Después de
  borrarlas, el automatismo no las recrea hasta el día siguiente.

### Sincronización P2P eliminada

- Se eliminaron los módulos Rust de sincronización, los comandos IPC, el panel
  de sincronización y el descubrimiento LAN por UDP.
- La app ya no escucha en la red ni modifica la bóveda en segundo plano.

### Cámara en Android

- El escáner usa la cámara nativa también cuando el user agent del WebView no
  contiene «Android», detectando la plataforma con `plugin-os`.
- Se mejoran los mensajes cuando el permiso de cámara está denegado o el sistema
  no vuelve a mostrar el diálogo.

### Actualización de la APK

- `latest.json` incluye la entrada `android-aarch64` con URL, tamaño y SHA-256.
- La app descarga el manifiesto y la APK con el plugin HTTP nativo, verifica el
  SHA-256 y guarda la APK en `Descargas/BetterTracker`. Si MediaStore no está
  disponible (Android antiguo), se abre el selector SAF para elegir destino.
- La instalación es manual, como en SinNotas: Android puede pedir permiso para
  instalar aplicaciones desconocidas.
- En escritorio se mantiene el actualizador firmado con minisign.

> **Android:** la APK sigue firmada con la misma clave que 0.8.7. Si vienes de
> una versión anterior a 0.8.7, desinstala una vez; desde 0.8.7 se instala
> encima con normalidad.
