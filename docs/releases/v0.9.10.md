# Better Tracker 0.9.10

Release de endurecimiento de seguridad. No cambia el formato de la bóveda
(`omega/`) ni de las copias (`longlife/`).

### Actualizaciones

- La app solo puede abrir el último instalador que ella misma descargó y
  verificó; se rechazan rutas relativas, UNC y componentes `..`.
- En Windows ya no se usa `cmd /C start`, así que una ruta con `&` no puede
  encadenar comandos.
- Los paquetes `.deb` y `.rpm` se verifican con SHA-256 **y** firma minisign
  antes de abrir el instalador. **Desde esta versión la firma es obligatoria**;
  las releases anteriores sin firma se aceptan con aviso y solo por SHA-256.
- El manifiesto `latest.json` se valida en CI antes de publicarse.

### Bóveda y permisos

- La lectura local ignora symlinks, limita la profundidad a 16 niveles y el
  tamaño por archivo a 8 MB.
- Solo se lee la estructura esperada (`omega/devices/<id>/events/` y el
  `events.jsonl` heredado).
- En Unix, directorios `0700` y archivos `0600` para configuración, eventos,
  copias y restauraciones.

### Superficie de la app

- Eliminados los plugins `fs`, `http` y `os` y sus permisos de webview.
- Los enlaces externos pasan por un comando Rust con allowlist del repositorio
  oficial y sus releases.
- CSP ampliada con `base-uri`, `form-action`, `frame-ancestors` y `object-src`
  en `'none'`.

### Cadena de suministro

- CI bloqueante con `cargo-deny`, `cargo-audit` y `npm audit`.
- Acciones de GitHub fijadas por SHA y Dependabot semanal para Actions, npm y
  Cargo.

### Privacidad

- La búsqueda de códigos de barras indica en la UI que el código se envía a
  Open Food Facts (`world.openfoodfacts.org`).
- README y README.es recuerdan que la bóveda se guarda como JSON en claro.

### Interfaz

- Panel dividido en pestañas: Resumen, Cuerpo, Nutrición y Recordatorios.
- Sidebar compacta (solo iconos) en ventanas de escritorio estrechas.

### Verificación

- `npx tsc --noEmit` correcto.
- `npm test`: 62 pruebas en 9 archivos.
- `npm run build` correcto.
- `cargo test`: 30 pruebas.
- `cargo clippy -- -D warnings`, `cargo deny check` y `cargo audit` correctos.
- `npm audit --omit=dev --audit-level=high`: 0 vulnerabilidades.

### Nota de actualización

- El flujo real de actualización (instalar 0.9.10 desde 0.9.9 en Linux,
  Windows y Android) se comprueba tras publicar esta release.
