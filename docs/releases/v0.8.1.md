# Better Tracker v0.8.1

- Nueva interfaz en cuatro secciones: Panel, Entrenamiento, Historial y Figura corporal.
- Logo original integrado en la app, el splash y los iconos compilados de Linux, Windows y macOS.
- Builds para Windows (NSIS/MSI) y macOS universal además de Linux (AppImage/DEB/RPM).
- Actualizaciones manuales, firmadas con minisign y verificadas antes de instalar.
- Manifiesto `latest.json` por plataforma/arquitectura y actualización automática solo para AppImage; DEB/RPM se actualizan manualmente.
- Claves de firma del updater en GitHub Actions Secrets; el repositorio solo contiene la clave pública.
- Correcciones de layout, calendario, heatmap, modales, figura corporal y precedencia del peso.
- Pruebas unitarias de métricas y verificación de artefactos en CI.

La bóveda sigue siendo JSONL append-only, local y sin cifrado. No hay cuentas ni telemetría; la única conexión es la comprobación manual de actualizaciones.
